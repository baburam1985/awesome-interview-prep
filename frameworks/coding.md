# Coding Interview Framework  
  
This document outlines a repeatable framework you can follow to solve coding interview problems systematically. Use it to structure your thinking and communication during interviews.  
  
## 1. Understand the Problem  
- Restate the problem in your own words to confirm understanding.  
- Identify the inputs and expected outputs.  
- Clarify constraints (time complexity, space limits, input sizes) and edge cases.  
- Ask follow-up questions if requirements are ambiguous.  
  
## 2. Plan Your Approach  
- Classify the problem type (e.g., array, string, tree, graph, dynamic programming).  
- Recall patterns and algorithms relevant to this problem type.  
- Discuss possible data structures and trade-offs.  
- Outline your algorithm in high-level pseudocode before coding.  
  
## 3. Write the Code  
- Define a clear function signature with descriptive parameter names.  
- Implement your planned algorithm step by step, narrating your thought process.  
- Keep the code clean: use meaningful variable names and helper functions if needed.  
- Handle edge cases gracefully.  
  
## 4. Test & Analyze  
- Run through simple and edge-case inputs verbally to test correctness.  
- Analyze time and space complexity of your solution.  
- Discuss potential optimizations and how they might affect complexity.  
  
## 5. Reflect & Iterate  
- Summarize the approach, highlighting strengths and trade-offs.  
- Mention alternative approaches and why you chose your solution.  
- If time permits, refactor for clarity or consider improvements.  
  
---  
Following this framework helps ensure that you address interviewer expectations: clarity, correctness, efficiency, and communication. Practice using it until it becomes second nature.
